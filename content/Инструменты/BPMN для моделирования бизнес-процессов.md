Для того, чтобы начать моделировать бизнес-процессы, аналитику нужно знать всего три вещи:
1. Нотация моделирования BPMN наглядна,  проста в изучении и является стандартом де-факто для многих компаний.
2. Библиотека bpmn-js - самый удобный инструмент для построения моделей бизнес-процессов. На её основе разработано множество программ и расширений для создания моделей, например, расширения для [[Obsidian для подготовки документации]] 
3. Плагин [bpmn-js-token-simulation](https://github.com/bpmn-io/bpmn-js-token-simulation) позволяет визуально проверить корректность построенной модели
Что касается инструментов моделирования - их множество. Наиболее интересными для аналитика на мой взгляд:
- **Сайт для создания модели в режиме онлайн** - https://demo.bpmn.io/new. Подойдет в случае если нужно быстро создать простую модель бизнес-процесса, нет необходимости / возможности устанавливать для этого на компьютер необходимое программное обеспечение. Созданную модель можно сохранить для дальнейшей доработки в формате *bpmn* или в виде изображения, в формате *svg*
- [Плагин BPMN](https://obsidian.md/plugins?id=bpmn-plugin) для [[Obsidian для подготовки документации]] - идет вместе с Token Simulation, так что после установки получаем полноценный инструмент для моделирования бизнес-процессов
  
Дополнительные полезные инструменты:
- Онлайн сервис для наглядного отображения различий двух bpmn-моделей - https://demo.bpmn.io/diff
